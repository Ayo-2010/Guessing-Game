# Guess My Number

Open `index.html` in your browser to play the game.

- Enter a number between the shown range and press the **Guess** button (or Enter).
- You have a limited number of attempts; the remaining attempts are shown on the scoreboard.
- The fewest attempts used to win is saved as the best score in your browser's `localStorage`.

Files:
- `index.html` — main page
- `Game.js` — game logic
- `style.min.css` / `style.css` — styles

No server required; just open the HTML file locally.
